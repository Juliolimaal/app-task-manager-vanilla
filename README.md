# App Task Manager - Estudos

Versão em Angular do app de tarefas que está na pasta `vanilla`.

## Requisitos

- Node.js 22.12 ou superior
- npm

## Executar localmente

Dentro desta pasta, rode:

```bash
npm install
npm start
```

Abra o endereço mostrado pelo Angular CLI (normalmente `http://localhost:4200`). Para gerar a versão de produção, use `npm run build`.

O projeto usa componentes separados para o quadro, as colunas, os cards e o formulário. As tarefas e os campos do formulário usam signals. Também dá para adicionar e excluir cards. Os dados não são salvos depois que a página é fechada.
